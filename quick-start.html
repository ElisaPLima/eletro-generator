🫀 ECG Builder - Guia Rápido

Bem-vindo ao ECG Builder! Uma ferramenta interativa para gerar eletrocardiogramas de 12 derivações com precisão médica, ideal para ensino e aprendizado.

🚀 Abrir ECG Builder

✨ Recursos Principais

  • 12 Derivações Completas: D1, D2, D3, aVR, aVL, aVF, V1-V6
  • Grade Médica Realista: Papel milimetrado rosa com escala 25mm/s e 10mm/mV
  • Cálculo Automático de BPM: Detecção de picos R e frequência cardíaca
  • Análise Automática: Interpretação completa do ECG com diagnósticos
  • Templates Prontos: Padrões comuns pré-configurados
  • Exportação: PDF vetorial e JPG alta resolução

🎯 Como Usar

1. Ajustar Parâmetros

Use o painel lateral esquerdo para modificar:

  • Frequência Cardíaca: 30-200 bpm
  • Intervalos: PR, QT, largura de P/QRS
  • Amplitudes: P, QRS, T, ST, U
  • Arritmias: FA, Flutter, TV, bloqueios AV
  • Bloqueios de Ramo: BCRD, BCRE, hemibloqueios
  • Patologias: IAM (várias localizações), HVE, HVD

2. Usar Templates

Clique nos botões na parte inferior do painel lateral:

  • ECG Normal: Padrão sinusal normal
  • IAM Anterior: Supradesnivelamento de ST em V1-V4
  • Fibrilação Atrial: Ausência de ondas P, RR irregular
  • BCRE: QRS alargado com padrão típico
  • HVE: Aumento de voltagem e padrão de sobrecarga

3. Análise Automática

Clique no botão "📊 Análise Automática" para obter:

  • Avaliação de frequência e ritmo
  • Medição de intervalos (PR, QRS, QT)
  • Cálculo do eixo cardíaco
  • Análise do segmento ST
  • Interpretação das ondas T
  • Diagnóstico geral com alertas

4. Exportar

  • Export as PDF: Documento vetorial de alta qualidade
  • Export as JPG: Imagem para apresentações

⌨️ Atalhos de Teclado

Ctrl+Z Desfazer última alteração
Ctrl+S Exportar para PDF
Ctrl+R Resetar para padrões
Ctrl+A Executar análise automática

🔬 Detalhes Técnicos

Modelo Matemático

O ECG é gerado usando soma de funções Gaussianas para cada componente da onda:

V(t) = Σ A_i × exp(-((t - μ_i)² / (2σ_i²)))

Derivações

  • Membros: D1, D2, D3 (Triângulo de Einthoven)
  • Aumentadas: aVR, aVL, aVF (Equações de Goldberger)
  • Precordiais: V1-V6 (Projeção vetorial 3D)

Precisão Médica

  • Velocidade do papel: 25 mm/s
  • Calibração de amplitude: 10 mm/mV
  • Caixas pequenas: 1mm × 1mm = 0.04s × 0.1mV
  • Caixas grandes: 5mm × 5mm = 0.2s × 0.5mV
  • Taxa de amostragem: 500 Hz

💡 Dicas e Truques

  • O BPM Calculado mostra a frequência real detectada no ECG gerado
  • Combine arritmias + patologias para casos complexos
  • Use templates como ponto de partida e ajuste conforme necessário
  • A análise automática é baseada em guidelines AHA/ESC
  • Abra o Console do navegador (F12) para acessar debugECG

🐛 Debug Console

Abra o console do navegador (F12) e use:

debugECG.getState() // Ver estado atual
debugECG.analyze() // Executar análise
debugECG.templates // Listar templates
debugECG.loadTemplate('afib') // Carregar template

📖 Exemplos de Padrões

IAM Anterior (STEMI)

  • Supradesnivelamento de ST em V1-V4
  • Infradesnivelamento recíproco em D2, D3, aVF
  • Possíveis ondas Q patológicas

Fibrilação Atrial

  • Ausência de ondas P
  • Intervalos RR irregularmente irregulares
  • Ondas fibrilatórias na linha de base

BCRE (LBBB)

  • QRS > 120ms
  • Onda R monofásica larga em V5, V6, D1
  • Ausência de Q em V5, V6
  • Padrão de sobrecarga (strain)
